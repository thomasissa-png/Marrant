# Parcours utilisateur — deviensmarrant.fr

## 1. Découverte → Inscription
1. L'utilisateur arrive sur la homepage
2. Il voit la blague du jour + le conseil du jour
3. Il clique sur "Commencer gratuitement"
4. Il s'inscrit via email ou Google
5. Il est redirigé vers la home connectée avec son streak à 1

## 2. Consultation quotidienne
1. L'utilisateur se connecte
2. Son streak s'incrémente
3. Il voit la blague + le conseil du jour
4. Il peut sauvegarder en favori
5. Il peut partager

## 3. Exploration blagues
1. L'utilisateur va dans la section Blagues
2. Il filtre par catégorie ou recherche
3. Il clique sur une blague → la chute se révèle
4. Il like/dislike
5. Il sauvegarde en favori

## 4. Progression conseils
1. L'utilisateur va dans la section Conseils
2. Il voit les conseils triés par niveau
3. Il lit un conseil → gagne des XP
4. Il fait l'exercice pratique
5. Sa barre de progression avance

## 5. Conversion Free → Premium
1. L'utilisateur atteint sa limite quotidienne (10 blagues ou 5 conseils)
2. Un modal s'affiche : "Passe Premium pour continuer"
3. Il clique sur "Passer Premium"
4. Redirection vers Stripe Checkout
5. Paiement → retour sur le profil avec badge Premium

## Parcours par persona

### Yanis (17 ans — répartie & confiance)
1. Arrive sur la home → voit "Confiance en soi" et "Répartie au quotidien" dans les tags
2. Clique "Découvrir mon profil humour" → Quiz
3. Sélectionne « Avoir de la répartie » → « Entre potes / au lycée » → « Mes blagues tombent à plat »
4. Résultat : "Le Novice Prometteur" → orienté vers /parcours débutant
5. Consulte les conseils de répartie → gagne ses premiers XP
6. Revient chaque jour → streak qui grandit, confiance qui monte
7. Profil : voit "Apprends les bases" → suit les conseils fondamentaux

### Sophie (26 ans — machine à café)

4. Consulte le conseil du jour sur le timing → gagne des XP
5. Le lendemain, revient pour de nouvelles blagues → streak à 2
6. Partage une blague en 1 clic depuis la carte
