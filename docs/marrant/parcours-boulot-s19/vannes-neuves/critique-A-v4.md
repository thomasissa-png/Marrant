## Doublons de structure dans le lot

1. **N5 / N11** : moule identique (« [Jour], j'ai voulu X. X a coincé, j'ai forcé : escalade. » / chute courte pince-sans-rire). En garder un seul.
2. **N8 / N13** : « Mon métier : … » / « Dans un centre de congrès, je … », puis chute sur un métier invisible ou mal reconnu.
3. **N13 / N15** : même thème (micro, parler sans être écouté).
4. **N10 / N12 / N16** : trois toasts de départ en « tu » adressés au partant ; N12 et N16 partent tous deux d'une formule toute faite (« porte ouverte », « on ne remplace pas »).
5. **N2 / N9 / N15** : format setup de 4 ou 5 mots puis chute de 2 à 4 mots. Le format marche, mais trois dans un lot de 16, c'est beaucoup.
6. **N4 / N6 / N14** : trois vannes sur le mail ou l'agenda ; N6 et N14 utilisent toutes deux le mot « vanne ».
