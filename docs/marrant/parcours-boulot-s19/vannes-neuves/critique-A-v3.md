## Doublons de structure dans le lot

1. **Mail + ligne cachée + « Correction / Rectificatif / Précision »** : N7, N13, N16. Trois fois la même mécanique, c'est le doublon le plus grave. N18 (« Pardon : ») utilise une auto-rectification voisine. Garder au plus une vanne de ce type (N13 sans son cadre devient une autre vanne).
2. **Chute « depuis [année] »** : N2 (2021), N5 (2019).
3. **Méta-discours** (le discours parle de lui-même) : N1, N8, N15. Garder N8.
4. **Machine qui parle + chute horaire ou réponse sèche** : N9, N14.
5. **« Je [métier] » + observation sur le public** : N3, N10, N17. Même attaque trois fois.
6. **Attente inversée humain / service** : N3 (je joue au robot), N6 (je fais patienter la hotline).
