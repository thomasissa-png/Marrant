# Relecture juridique de l'implémentation s16 (@legal, 07/10/2026)

Brief compris : relecture seule (aucun fichier modifié hors ce rapport) des 8 points juridiques du parcours abonnement, sur le code commité et les aperçus d'e-mails. Draft de référence, pas un avis d'avocat. D3 exclu. Chemins relatifs à `apps/web/src/`. Sources web : [décret 2023-417 (Deloitte Avocats)](https://blog.avocats.deloitte.fr/la-resiliation-en-3-clics-nouvel-outil-au-service-des-consommateurs/), [Seban Avocats](https://www.seban-associes.avocat.fr/la-resiliation-des-contrats-conclus-par-voie-electronique-en-trois-clics/) (texte exact de D.215-3 non relu sur Légifrance : `[À VÉRIFIER]`).

**Risques restants en 5 points** : (1) médiateur toujours sans nom (CGU art. 9) et identité du vendeur absente (D3), seuls P0 restants, dépendent de Thomas ; (2) suppression de compte avec abonnement payé : perte sans avertissement clair ni remboursement ; (3) bouton « Résilier ton contrat » qui disparaît si la lecture du résumé échoue ; (4) formule mensuelle toujours « reconduite tacitement » (L.215-1) ; (5) bouton Stripe « S'abonner » sans mention explicite d'obligation de paiement.
