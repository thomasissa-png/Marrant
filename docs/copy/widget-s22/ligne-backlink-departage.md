# Départage à l'aveugle : phrase de la ligne de backlink (s22)

Phrase évaluée (seule partie lue de `ligne-backlink-final.md`) :

```
Le code ajoute sous le cadre une petite ligne « La vanne du jour par Deviens Marrant », avec un lien vers notre site. Elle est facultative : pour l'enlever, efface la fin du code, à partir de « <p ». Si tu la gardes, c'est un coup de pouce pour nous, merci !
```

## Note 1 : blogueuse WordPress non technique : 9/10

- **Je comprends ?** Oui. Je sais ce qui va apparaître (le texte exact de la ligne, sa place sous le cadre, le fait qu'il y a un lien). Le repère « <p » se trouve facilement dans un bloc HTML personnalisé, et « la fin du code » me dit que j'efface jusqu'au bout.
- **Je me sens libre ?** Oui. « Facultative » arrive avant toute demande, et la marche à suivre est donnée tout de suite, sans détour.
- **J'ai envie de la garder ?** Plutôt oui. Le « coup de pouce, merci ! » est sympa, sans culpabiliser.
- Petit point (pas bloquant) : avec les guillemets autour de « <p », on peut se demander une seconde s'il faut chercher les guillemets aussi. Le contexte lève le doute.

## Note 2 : responsable com prudent : 9/10

- **Clair :** une info par phrase (ce que c'est, comment l'enlever, pourquoi la garder).
- **Exact :** le code tient sur une ligne et se termine par le paragraphe `<p style="…">…</p>`. Effacer à partir de « <p » jusqu'à la fin retire exactement la ligne, et laisse le cadre intact. Le lien obligatoire est dans le cadre, pas touché par la consigne, et la phrase ne prétend pas le contraire (« Elle » renvoie à la ligne seule).
- **Honnête :** le lien vers notre site est annoncé, l'intérêt pour nous est assumé (« coup de pouce pour nous »).
- **Pas de manipulation :** aucune pression, aucune fausse urgence, le merci est léger.
