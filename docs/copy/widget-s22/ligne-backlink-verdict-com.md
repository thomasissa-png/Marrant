# Verdict relecture à l'aveugle (responsable com de PME, prudent)

**Choix : C. Note : 8/10** (A : 7/10, B : 6/10). Sous 9, donc texte de remplacement ci-dessous.

**Pourquoi :** C est la seule qui dit que la ligne « s'ajoute » (donc que c'est le code qui la met, pas moi) et qu'il y a un lien vers leur site ; son « retire-la si elle ne colle pas à ton site » est le plus naturel. Il lui manque deux choses : « on te dit merci » sonne comme un échange de bons procédés flou, et rien n'indique où se trouve la ligne dans le code ni comment l'enlever (A est sec, B est trop familier pour une validation en interne).

## Texte prêt à coller

```
Le code ajoute sous le cadre une ligne « La vanne du jour par Deviens Marrant », avec un lien vers notre site. Elle est facultative : tu peux l'enlever. Si tu la gardes, ça nous fait connaître, et merci.
```

À vérifier avant mise en ligne (je ne l'invente pas) : si la méthode pour enlever la ligne est simple (une ligne de code à supprimer), la nommer en 5 mots après « l'enlever » ; sinon un com prudent hésite à coller.
