# QR6 : critique à l'aveugle, tour 2

Règles dures : 0 tiret cadratin, 0 émoji, 0 IA, 0 concurrent, guillemets « » et “ ”. Accords : aucun dans les répliques ; la scène P1 dit « un de tes parents » (neutre), G2 « cette personne ». Checklist relue : le moule « je fais X si Y » est absent, les scènes ne portent pas leur signal (P1 « en tendant ton écharpe » est un détail de la sûre, pas de la scène). Motif « manteau » en double (L2 joueuse, P1) : préférence, change L2 en « les vestes sur mon lit ».
Web (recherche de l'idée, 3 requêtes) : aucune occurrence pour le club des choses qui traînent, la sérénité dans le tiroir ni le veto « court au ralenti ». Preuve partielle : ces trois idées sont de formes courantes (le « club de X », « as-tu pris ton calme ? », la course au ralenti comme gag de film), donc plus proches du connu que ne le dit l'auteur.
Verdict : GO seulement à 10, aucune situation n'y est. Moyenne 7,6.
