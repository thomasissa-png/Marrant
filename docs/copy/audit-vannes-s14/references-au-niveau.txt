# Les 30 vannes validées à l'aveugle (30/09) : références de niveau, à NE PAS réécrire ni recopier
- Mon détecteur de fumée me sert de minuteur. La dernière fois, les pompiers sont venus. // Ils m'ont laissé un avis Google : une étoile.
- Mon psy m'a dit que je devais arrêter de me comparer aux autres. // J'ai vérifié, les autres n'ont pas ce problème.
- J'ai regardé les prix des pass 3 jours pour les Eurockéennes. // Je vais acheter une guitare.
- Ma copine a fait le tri de printemps. Elle a gardé mon vélo, mes livres, ma guitare. // Moi, elle a dit qu'elle verrait en juin.
- J'ai installé un jeu de 120 Go. J'y ai joué 20 minutes. C'était nul. // Je l'ai pas désinstallé. On a fait le téléchargement ensemble.
- Elle m'a demandé ce que je faisais dans la vie. // J'ai dit « des erreurs, principalement ». Elle a ri. Puis elle est partie.
- Mon collègue revient de 4 jours à Rome et me raconte tout en détail. // Ça fait 2h. On vient de récupérer les valises.
- J'ai attendu mon bus sous la pluie ce matin pendant 20 minutes. // Il était à l'heure, moi j'étais à l'arrêt d'en face.
- Mon GPS m'a dit de tourner à droite. Y'avait un fleuve. // J'ai hésité. Il avait l'air sûr de lui.
- J'ai dit à mon chat qu'on allait chez le vétérinaire. // Depuis, il cherche « droits des animaux » sur mon ordinateur.
- Ma mère m'appelle chaque dimanche pour savoir si je mange bien. Je réponds oui. // Elle entend le papier alu. Elle insiste pas.
- J'ai téléchargé une app pour compter les calories. J'ai rentré ma journée. // Elle m'a demandé si tout allait bien.
- J'ai dit à Alexa de me raconter une blague. // Elle m'a lu mon historique de recherches.
- J'ai mis mon réveil en face du lit pour être obligé de me lever. // Maintenant je dors par terre, à côté du réveil.
- Ma collègue m'a briefé pendant 45 minutes avant ses congés pour me passer ses dossiers. // Elle revient lundi.

- Elle m'a demandé mon love language. J'ai répondu « envoyer des memes à 3h du mat ». // Elle m'a demandé si j'en parlais un autre.
- Mon copain et moi, on a trouvé comment choisir un resto sans se disputer. // On se fait livrer et on chuchote, comme si on était sortis.
- Mon copain : 'Choisis le resto, ça m'est égal.' // J'ai réservé chez son ex. Ça lui était égal aussi.

- J'ai bloqué quelqu'un sur les réseaux. Il m'a appelé pour demander pourquoi. // J'ai décroché. J'ai dû mal comprendre le principe.

- Mon ambition dans la vie, c'est d'être aussi confiant... // Que le mec qui répond « à peu près » quand on lui demande s'il sait nager.
- J'ai couru pour attraper le bus ce matin sous la pluie. // Le chauffeur m'a fait un petit signe de la main en passant.
- Mon père a vu mon appart. Il a dit « c'est pas mal ». // Je lui ai demandé de me le mettre par écrit.
- Quand quelqu'un commence par « à la base », il faut être patient. // Trois digressions plus tard, la base a déménagé.
