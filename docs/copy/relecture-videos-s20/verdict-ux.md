## Remarques transversales (pas bloquantes item par item)

- Tics répétés dans les descriptions : « le titre l'annonce / le titre le dit / le titre donne le ton » (A11, A12, A19, A35, A46, B16, B17, B21, B23, B35), « s'attaque à / s'empare de », « terrain rêvé / idéal », « un bon modèle pour ». Varier avant mise en ligne pour éviter l'effet gabarit.
- Conseils qui se contredisent entre fiches : B27 (« joue ton énergie un cran au-dessus ») et B28 (« joue un cran en dessous ») ; A46 (« si le texte est absurde, le corps doit l'être aussi ») et A31, A34, B41 (sérieux impassible, aucun clin d'œil). Ajouter à chacun son contexte (énergie vs intensité de la chute ; sketch physique vs vanne sèche).
- Doublons de technique : personnage joué à 100 % sans clin d'œil (A07, A34, B41), actualité comme matière (A22, A29, B45), mot en moins / phrase ciselée (B40, B43), faits vrais vers conclusion absurde (A37, B36).
- Les exercices avec exemple concret sont les plus utiles (A07, A15, A21, A22, B15, B19, B28, B37) ; garder cette forme.
