## Bilan

- **34 oui, 11 oui\* (au niveau si le fait est confirmé), 14 non** sur 59.
- **Non** : C01, C08, C09, C10, C18, C20, C27, C29, C36, C38, C47, C48, C52, C58. Toutes les corrections tiennent en une phrase, aucune idée n'est à jeter.
- **Les 3 plus graves** : C27 (année fausse affichée en public), C08 (tout l'angle pédagogique repose sur un trait du personnage qui ne se déduit pas du titre), C29 (le critère de réussite de l'exercice contredit le principe de la chute).
- **Défaut récurrent** : sur les fiches les plus faibles, la description affirme ce qui se passe dans la vidéo (jeu physique, posture, malaise de la salle) au lieu d'orienter le regard (« regarde si… », « regarde comment… »). Les fiches réussies (C11, C12, C14, C37) posent une question d'observation sans rien affirmer : c'est le modèle à suivre.
- **Redondance dans le catalogue** : C20, C38 et C42 répètent le même enseignement (situation vécue par tous, « droit à la vanne »). Ce n'est pas bloquant, mais il faut les différencier si elles sont visibles sur une même page.
- **Forme** : zéro tiret cadratin, tutoiement respecté partout, guillemets « » corrects. Les fautes de langue isolées (C01, C09, C52, C58) sont corrigées dans le tableau.
