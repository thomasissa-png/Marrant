**Méthode** : recherche web limitée à youtube.com, par humoriste (« Roman Frayssinet Montreux Comedy », « Waly Dia Montreux Comedy sketch », « Panayotis Pascot stand-up extrait Presque Netflix », « Marina Rollman Montreux Comedy », « Haroun stand-up extrait spectacle officiel », « Thomas Ngijol Jamel Comedy Club », « Bun Hay Mean sketch Montreux Comedy Jamel Comedy Club », « Fary / Kyan Khojandi / Élodie Poux / Alban Ivanov / Baptiste Lecaplain / Fabrice Éboué / Ahmed Sylla / Thomas VDB / Nora Hamzawi … Montreux Comedy », « Florence Foresti sketch personnage extrait officiel »), plus « Bun Hay Mean mort humoriste » sur le web ouvert. Chaque lien vérifié le 13/11/2026 par l'oEmbed public de YouTube (titre exact et nom de la chaîne renvoyés ; chaîne retenue seulement si officielle : festival, diffuseur ou humoriste). Les 31 identifiants comparés au code du site et aux documents (`apps/web/src`, `docs`) : aucun n'est en ligne sur le site ; deux sont cités dans un document d'audit (signalé).

**Limites** : (1) aucune vidéo regardée, donc aucun mécanisme confirmé ; (2) durées et minutes illisibles (la page YouTube renvoie vers une page de consentement) ; (3) aucune transcription ni citation écrite trouvée, pour aucun passage ; (4) descriptions de vidéos lues dans les résultats de recherche, pas sur la page ; (5) aucune recherche de controverse récente sur les humoristes (à faire la semaine de publication, comme pour les lettres) ; (6) Mirabel, les passages déjà pris par les lettres et les vidéos déjà en ligne sont exclus, mais les fiches existantes du site (Haroun, Rollman, Khojandi, Lecaplain) n'ont pas été relues pour vérifier qu'aucune technique ne se répète.
