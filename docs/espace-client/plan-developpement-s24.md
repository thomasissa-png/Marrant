## 2. Règles de développement communes (brief §5.4, CLAUDE.md, chaque lot)

1. **Un seul interrupteur** : `apps/web/src/config/espace-client.ts` exporte `ESPACE_CLIENT_PUBLIE = false` (même patron que `BOULOT_PUBLIE`). Fermé : toute route `/mon-espace/**` et toute route `api/espace/**` répondent comme une adresse inexistante (`notFound()` / 404 JSON), aucune écriture en base, aucun composant de l'espace monté (la sous-barre, la cloche, l'entrée « Mon espace » ne sont pas rendues), `/profil`, `/parcours`, `/favoris`, l'en-tête et le pied de page sont **octet pour octet** ceux de la production.
2. **Test d'inertie permanent** (créé au lot D0, relancé à chaque lot) : Jest compare le HTML rendu de `/profil`, `/parcours`, `/parcours/[slug]`, `/favoris`, `/vannes`, `/conseils`, `/videos`, `/carnet`, `/abonnement`, `/abonnement/success` avec flag fermé à une référence prise sur `main` avant le premier lot (`apps/web/src/**/__snapshots__/inertie-espace.snap`) ; Playwright vérifie 404 sur `/mon-espace`, `/mon-espace/questions` et 0 requête vers `api/espace/*` depuis les pages publiques.
3. **Environnement vide** pour build, tsc, lint, Jest, Playwright : `env -i` + variables factices du job `e2e-local` ; jamais `env` ni `printenv` non filtré (lessons-learned n°17 et n°21). Consigne recopiée dans chaque prompt @fullstack et @qa, avec `ANTI-TIMEOUT : écris le fichier IMMÉDIATEMENT après lecture. Write d'abord, Edit ensuite.`
4. **Pre-commit** de chaque lot touchant `src/` : `npx tsc --noEmit -p tsconfig.build.json && npx next lint && npm run build` ; si des tests changent : `npx tsc --noEmit` (config complète) et Jest sans secrets Stripe. Clôture d'un lot : CI GitHub verte sur le dernier commit.
5. **Migrations additives numérotées à la suite de 18**, idempotentes, jouées 2 fois sur base jetable avant tout déploiement (critère de chaque lot qui en a une). Aucune table existante modifiée sauf mention (`Joke`, ajout d'une colonne au lot D3).
6. **Premium côté serveur** : plan relu EN BASE (jamais le seul jeton de session) par `lib/espace/garde.ts` ; tout champ réservé passe par `lib/champs-premium.ts` (`sansExercice*`) ; test automatisé « compte non Premium : aucun champ `howToApply`, `exercise`, `learnings`, aucune fiche neuve dans le HTML ni l'API » sur CHAQUE route neuve.
7. **Design** : tokens existants seulement (D1), aucun `#hex` ni `[Npx]` (grep automatique dans les fichiers de l'espace), 44 px de cible, focus visible, `prefers-reduced-motion`, aucun émoji (la prop emoji de `EmptyState` devient optionnelle, retouche minimale).
8. **Textes** : tout libellé vient de `docs/copy/libelles-espace-e5-s24.md` (validé, 4 tours) ou d'un texte validé du code ; tout texte neuf passe la relecture à l'aveugle (2 sur 3 minimum pour un libellé, 10/10 pour un contenu) AVANT d'entrer dans `config/textes/espace-*.ts`. Contrôle automatique : zéro tiret cadratin, zéro émoji, zéro concurrent nommé, zéro mention d'IA dans ces fichiers.
9. **Captures** nommées `tests/screenshots/espace-<écran>-<état>-<largeur>.png`, thème sombre, largeurs 320, 375, 768, 1280 (plus 1024 et 1536 pour la barre), lues une à une par @design (10 critères PASS/FAIL).
10. **`REPLIT_ACTIONS.md`** : une entrée « À DÉPLOYER » créée au lot D0 et complétée à chaque lot (migrations, variables, ordre P0 à P8). Aucun déploiement sans go écrit de Thomas.
